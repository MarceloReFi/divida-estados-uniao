# 💰 Dívida dos Estados com a União

Aplicação interativa para análise da dívida consolidada dos estados brasileiros com a União Federal.

## 📊 Objetivo

Desmentir narrativas comuns sobre a economia brasileira através de dados oficiais do Tesouro Nacional.

## 🎯 Insights Principais

- **Sudeste concentra 65% da dívida total**
- **SP + Sul = ~48% da dívida**
- **Norte + Nordeste = ~14% da dívida**

## 🔧 Tecnologias

- Python 3.11
- Streamlit
- Pandas
- Plotly

## 📈 Dados

Fonte: Tesouro Nacional - Dívida Consolidada dos Estados (PAF)
Período: 2015-2022

## 🚀 Como Rodar Localmente
```bash
# Clonar repositório
git clone https://github.com/MarceloReFi/Desmistificando-a-Economia-Brasileira.git
cd Desmistificando-a-Economia-Brasileira

# Criar ambiente virtual
python -m venv venv
source venv/bin/activate  # Mac/Linux

# Instalar dependências
pip install -r requirements.txt

```
